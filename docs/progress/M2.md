```
Internet
    ↓
Connector (MEXTConnector)
    ↓
FetchResult
    ↓
RawDocumentMapper → RawDocumentRepository → raw_document table
    ↓

    ↓

    ↓

    ↓

```

## Known Limitations

1. **Repository owns transaction boundaries** — commit() inside save(). Will need UoW for batch processing. (TD-001)
2. **Mapper performs DB lookups** for reference resolution. (TD-002)
3. **Country/provider resolution** uses exact string matching. No normalization. (TD-003)
4. **No batch persistence** — one entity at a time. (TD-004)
5. **Duplicate detection** implemented but not wired into persistence flow. (TD-007)
6. **application_cycle** always NULL — extraction schema gap. (TD-008)
7. **No composite index** for find_duplicate query. (TD-009)
8. **MockLLM only** — real LLM integration not yet implemented.
9. **Single connector** — only MEXTConnector. DAAD, Chevening, LPDP connectors pending.
