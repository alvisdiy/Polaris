## 3. Cara menjalankan

```bash
# 1. Database + reference data
alembic upgrade head
python scripts/seed_source_registry.py
python scripts/seed_provider_discovery_config.py

# 2. API + SPA
uvicorn api.app:app --port 8000
# frontend dev: cd frontend && npm run dev

# 3. Status per negara
python scripts/country_status.py

# 4. Cari beasiswa per negara (exhaustive)
python scripts/run_country_crawl.py JP --discover --max-total-pages 300

# 5. Review
python scripts/review_queue.py summary
python scripts/review_queue.py list --limit 20
python scripts/review_queue.py approve <id> --actor owner --reason "verified" --yes
```

Docker:

```bash
export POLARIS_ADMIN_TOKEN=$(python -c "import secrets; print(secrets.token_hex(32))")
docker compose up --build
```

3. **Kelengkapan deadline/funding** rendah (38%/36%). Ini menurunkan kualitas matching dan filter.
4. **Importer JASSO/JSPS/universitas** belum ada; baru database Study in Japan.
5. **166 extraction failures** dari 693 halaman; sebagian besar halaman policy/overview yang ditolak gate — perlu triage.
6. **UI review** belum ada; CLI cukup untuk satu operator.
