# Definition of Done (DoD)

A milestone is considered complete only when ALL of the following are satisfied.

## Code

- Builds successfully
- No lint errors
- Type hints complete
- No duplicated logic
- Naming follows Engineering Standards

## Database

- Models implemented
- Relationships validated
- Constraints validated
- Indexes reviewed
- Alembic migration generated
- Migration upgraded successfully
- Migration downgraded successfully
- Migration upgraded again successfully

## Testing

- ORM validation completed
- Unit tests added
- Existing tests pass

## Documentation

- Documentation reviewed
- No documentation conflicts
- Required documentation updated if architecture changed

## Review

- Self-review completed
- Architectural review completed
- Risks documented

## Git

- Ready for commit
- Commit scope limited to current milestone

A milestone is NOT complete if any item above is missing.
